# 住房维修基金记账系统 · 使用说明书

（适用于 Windows 桌面版 v1.x。财务口径依据《住宅专项维修资金会计核算办法》财会〔2020〕7号）

---

## 一、安装与启动

1. 将发放的压缩包**整个解压**到电脑上（建议 D 盘或桌面新建一个文件夹，如 `D:\维修基金记账`）
2. 双击 `vfund.exe` 即可运行，**无需安装**，无需联网
3. 首次运行会自动在 exe 旁边生成一个 `data` 文件夹（存放全部账务数据）和一个 `vfund.log`（运行日志）

> 系统要求：Windows 10 / 11。若杀毒软件拦截，选择"允许运行"（本软件只在本机内部通信，不上传任何数据）。

## 二、登录

- 默认账号密码均为 `admin`
- 登录后有效期为 24 小时，超时需重新登录；页面右上角可退出
- 如需修改密码，请联系系统管理员设置（通过系统环境变量 VFUND_USER / VFUND_PASS 配置后重启软件）

## 三、首次使用（建账五步）

按左侧菜单依次操作：

1. **基础数据 → 建小区**：填写小区名称、资金性质（商品住宅/公有住房）
2. **基础数据 → 建楼洞**：选择所属小区，填写楼洞名称
3. **基础数据 → 导入住户**：推荐先"下载导入模板"，按模板整理 Excel 后"选择文件导入"（含期初余额）；也可以逐个手工新增
4. **基础数据 → 小区设置**：设置该小区**首期交存标准**（元/㎡，用于 30% 续筹红线提示）和**公共账期初**（启用本系统前未分配的利息等）
5. **账簿查询 → 试算与对账 → 生成期初凭证**：对每个小区点"生成期初凭证"，启用财务账套前的老凭证用"历史补账"补齐

## 四、日常记账

### 1. 缴存收款（日常录入 → 录入收款）

- 选小区 → 楼洞 → 户号，填写金额、缴款方式，可上传收据图片；点"保存"即生成凭证
- 大批量收款：点"批量导入"，按模板整理银行代收流水后一键导入，系统自动逐笔生成凭证，**重复流水会自动拦截**

### 2. 维修支出（日常录入 → 录入维修支出）

- 选小区和分摊范围：全体楼洞 / 指定楼洞 / **勾选指定住户**
- 填写维修项目、金额，系统按建筑面积自动分摊（尾差归最后一家）
- 保存前会弹出分摊预览：**若部分住户余额不足会明确列出差额**，确认后仍可保存（该户会出现负余额，请酌情处理）

### 3. 其他业务

| 业务 | 入口 | 说明 |
|---|---|---|
| 利息收入 | 日常录入 → 录入利息 | 计入小区公共账 |
| 收益分配 | 日常录入 → 利息分配 | 把公共账利息按面积分配到各户 |
| 返还/退返 | 日常录入 → 返还退返 | 灭失返还/退返交存，均减少该户余额 |
| 其他收入 | 日常录入 → 其他业务 | 经营收入、共用设施处置收入等 |
| 备用金 | 日常录入 → 其他业务 | 提取/退回；维修支出可用备用金付款 |
| 国债投资 | 日常录入 → 其他业务 | 购买/到期兑付（利息自动入账） |
| 银行对账 | 账务处理 → 银行对账 | 导入银行流水，按金额匹配凭证 |

### 4. 凭证管理

- 每笔业务保存后自动生成**汇总记账凭证**（按小区+日期汇总，摘要注明笔数），可在"账务处理 → 凭证查询"查看、打印
- 录错金额：点"作废"并填写原因（留痕，不删除）；涉及分摊的凭证作废会连同子凭证一起作废
- 特殊事项（无业务单据）可在"账务处理 → 凭证录入"手工填制凭证，借贷必须平衡
- 凭证可上传附件（收据、合同扫描件等）

## 五、期末结转

**期末业务**页面：

- **月末结转**：每月做完后点一次。收入/支出转入维修基金净资产，同时自动生成当月月报表和财务报表快照。**不锁账**：之后改账会自动作废结转结果，重新点一次"月末结转"即可
- **反结转**：撤销当月结转（改账时用）
- **年度结转**：年底点一次，自动结转年内所有月份并生成年度财务报表
- 关闭软件时如有未结转月份，系统会弹窗提醒

## 六、报表查询与导出

- **账簿查询 → 财务报表**：资产负债表、收支表、净资产变动表（财会〔2020〕7号三张附表），支持屏幕查看、**预览打印、下载 PDF、导出 Excel**；报表不平或有异常时页面会给出诊断提示
- **账簿查询**：总账、明细账（可按小区汇总）、科目余额表、试算与对账
- **业务台账 → 四级账簿**：小区账 → 楼洞账 → 住户账逐级下钻；可打印/导出**分户余额表**（余额低于首期交存额 30% 的户标红提醒续筹）和**小区对账单**（按年度，供业委会核对）

## 七、⚠ 重要注意事项（务必阅读）

1. **`data` 文件夹就是你的全部账务，绝不能删除或移动**
   - 里面是数据库、凭证附件、报表快照。误删将导致账务丢失
   - 升级软件时**只替换 `vfund.exe` 文件本身**，不要动 `data` 文件夹
   - 换电脑时：把 `vfund.exe` 和 `data` 文件夹**一起**拷到新电脑，双击即可继续使用

2. **定期备份，重要数据及时导出留痕**
   - 建议每周（至少每月结转后）把整个软件文件夹复制一份到 U 盘或网盘
   - 每期结转后、年底年结后，把三张财务报表和月报表**导出 Excel/PDF 另行存档**，这是审计留痕最稳妥的方式
   - 电脑重装、中毒、硬盘损坏前，先确认备份已做

3. **作废操作不可恢复**：作废会保留记录（留痕）但金额即行冲销，作废前请核对凭证号

4. **不要直接打开数据库文件**：`data/vfund.db` 是系统内部文件，用记事本/Excel 打开会损坏数据，一切操作请通过软件界面完成

5. **凭证日期请按真实日期填写**：涉及月结/年结归属，改账请用"作废+重新录入"，不要跨月乱填日期

6. **打印**：预览打印依赖系统打印对话框；PDF 下载的文件可直接打开或发送存档

7. 软件运行时若弹窗提示错误，请查看 exe 旁 `data/vfund.log` 的最后几行，联系管理员时附上该日志

## 八、常见问题

| 问题 | 处理 |
|---|---|
| 双击没反应 / 提示缺文件 | 确认整个压缩包已完整解压（不能只拷出 exe）；win7 及以下不支持 |
| 打开后是空白窗口 | 关闭软件，把 `data/vfund.log` 发管理员排查 |
| 忘记密码 | 联系管理员重置（环境变量配置） |
| 数据在哪里 / 怎么备份 | exe 旁的 `data` 文件夹，整个复制即备份 |
| 报表"不平"怎么办 | 按页面上的诊断提示处理：未建期初 → 生成期初凭证；改账后 → 重新结转；老凭证 → 历史补账 |
| 换电脑 | exe + data 文件夹一起拷走 |
