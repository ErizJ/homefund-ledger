# 住房维修基金记账系统（homefund-ledger）

面向住建部门代管住宅专项维修基金场景的单机记账系统。业务台账与财务账套双线运行、同源勾稽，财务口径按《住宅专项维修资金会计核算办法》（**财会〔2020〕7号**）：收付实现制、借贷记账法、商品住宅与已售公有住房分账核算。

- **后端**：Go + Gin + SQLite（modernc 纯 Go 驱动，免 CGO），端口 `8080`（可用环境变量 `VFUND_PORT` 覆盖）
- **前端**：Vue3 + Vite + Element Plus，端口 `5173`（开发模式自动代理 `/api` 到后端）
- **数据**：本地 SQLite 文件 + 附件目录，全部数据不出本机

---

## 一、业务台账（四级分户账）

```
一级 总账（全局汇总）
 └─ 二级 小区账（每个小区一本账）
     └─ 三级 楼洞账（每个楼洞一本账）
         └─ 四级 住户账（每户一账，所有收支流水落到最细级）
```

- 户余额 = 期初建账 + 缴存 + 收益分配 − 维修分摊 − 返还/退返
- 小区余额 = 户账合计 + 公共账（公共账期初 + 利息 + 其他收入 − 已分配收益）
- 首页/四级账簿/住户管理/对账单/月报均与该口径同源实时计算

### 日常录入（业务凭证类型）

| 类型 | 说明 |
|---|---|
| 缴存收款 | 记到户；支持**批量导入交存流水**（银行代收文件，同日同户同金额判重） |
| 维修支出 | 分摊范围：全体楼洞 / 单楼洞 / **指定多户**；按建筑面积自动分摊，尾差归末户；保存前预览并提示余额不足的户 |
| 利息收入 | 挂小区公共账 |
| 收益分配 | 公共账按建筑面积分配到各户（借 待分配累计收益 / 贷 维修资金） |
| 返还/退返 | 灭失返还（借 返还支出 / 贷 银行）、退返交存（冲减交存收入），均减少该户余额 |
| 其他收入 | 经营收入(4201) / 共用设施处置收入(4301) / 其他收入(4901)，计入公共账可分配收益 |
| 备用金 | 提取/退回（1201）；维修支出支持"备用金"付款方式 |
| 国债投资 | 购买（借 国债投资 / 贷 国债专户）、到期兑付（本金+利息，利息计入国债利息收入并同步挂业务凭证） |

- 每笔业务凭证记录**制单人**；作废须填**原因**、记录作废人，留痕不删除
- 手工收款 10 分钟内同户同日同金额同摘要判重拦截；所有保存按钮带 loading 防连点

## 二、财务账套（财会〔2020〕7号）

### 科目表（45 个预置科目，支持自定义）

资产：1001 银行存款（商品/公房/国债专户）、1101 国债投资、1201 备用金
负债：2001 应付房屋灭失返还资金
净资产：3001 商品住宅维修资金、3002 已售公有住房维修资金、3101 待分配累计收益
收入：4001 交存收入、4101 存款利息收入、4102 国债利息收入、4201 经营收入、4301 共用设施处置收入、4901 其他收入
支出：5001 维修支出（500101 工程维修费 / 500102 监理费 / 500103 检测费、勘察设计费 / 500104 其他维修相关费用）、5101 返还支出、5901 其他支出

- **科目自定义**：基础数据页可新增/改名/改编码（分录级联迁移）/停用/删除；一级科目自动出现在三张财务报表，子科目编码 = 上级+01/02 自动归入商品/公房分栏

### 记账凭证（按小区×日期汇总）

- 业务单据落账后，系统按**小区 × 日期**生成一张汇总记账凭证：当天全部业务借贷分录按科目+方向合并（摘要注明笔数，如"交存收入120笔"）
- 业务新增/作废自动重建当日汇总凭证；凭证号按当月最大号+1 生成（断号安全）
- 手工记账凭证在「凭证录入」页填制（借贷平衡校验），用于无业务单据的特殊事项
- 凭证查询/打印/附件/作废留痕齐全，来源标签区分 汇总凭证/手工录入/期初建账/月末结转

### 结转与反结转（不锁账）

- **月末结转**：交存收入 → 商品住宅/已售公有住房维修资金；利息等收益 → 待分配累计收益；支出 → 维修资金。可重复执行（按最新账目重算，幂等），同时生成月报表与财务报表快照
- **年度结转**：一键结转年内所有有收支的月份，生成年度财务报表快照（本年数/上年数口径）
- **反结转 / 反年度结转**：撤销结转凭证与结转记录
- 不锁账：结转后仍可随时记账/作废，**改账自动使对应月份结转失效**，重新点结转即可
- 期初建账：按小区生成期初凭证（户账期初→净资产，公共账期初→待分配收益）；启用财务账套前的老凭证用「历史补账」一键补齐

### 财务报表（会住维01/02/03表，分栏式）

- **资产负债表**：商品住宅/已售公有住房/合计三栏，年初余额（上年末推导）+ 期末余额，自动平衡校验
- **收支表**：月度（本月数/本年累计数）或年度（本年数/上年数），剔除结转凭证的净发生额口径
- **净资产变动表**：上年年末 → 本年收支差额 → 本年分配累计收益 → 其他变动（反推勾稽）→ 本年年末
- 三张表均支持：屏幕查看、**PDF 下载**（嵌入中文字体）、**预览打印**、Excel 导出；月结/年结时自动生成快照存档
- **诊断引导**：未建期初/未结转/未补账等情况自动提示并指向处理页面

### 账簿查询

- 总账（三栏式）、**明细账（默认按小区汇总：科目×小区 借贷合计/净额/笔数，可切逐笔明细）**、科目余额表、试算平衡、财务账↔业务台账双线对账

## 三、其他功能

- **银行对账**：导入流水（Excel/CSV），按同金额找候选凭证人工匹配，未达账项标记
- **分户余额表 / 小区对账单**：打印与 Excel 导出（对账单按年度，供与业委会核对）
- **30% 续筹红线**：按"首期交存标准 × 面积"计算，余额低于 30% 的户在住户管理/四级账簿/分户余额表标红
- **基础数据导入**：Excel/CSV 导入住户（含期初余额）、模板下载、手工建小区/楼洞、小区设置（首期标准/公共账期初）、编制单位设置、会计科目管理
- **登录**：单用户账号密码（默认 admin/admin，可用 VFUND_USER/VFUND_PASS 覆盖），24 小时会话 Cookie，页面顶栏显示用户与编制单位

## 四、启动方式

### 1. 后端

```bash
cd server
./vfund-server /绝对路径/vfund.db
```

- 附件目录 `uploads/`、报表目录 `reports/` 自动建在数据库同级
- 启动自动完成建表、迁移、科目预置（老库自动升级：金额列转"分"、凭证类型扩展、科目编码对齐办法附录）

### 2. 前端

```bash
cd web
npm install   # 依赖丢失时
npm run dev
```

浏览器打开 **http://127.0.0.1:5173**（开发模式自动代理 `/api` 到 8080）。

### 3. （可选）重新编译后端

```bash
cd server
go build -o vfund-server .
```

## 五、典型使用流程

1. **首次建账**：基础数据 → 建小区/楼洞 → 导入住户（含期初余额）→ 小区设置（首期交存标准、公共账期初、编制单位）
2. **日常**：首页/日常录入 → 收款（可批量导入）→ 维修支出（自动分摊）→ 利息/其他收入 → 收益分配 → 返还/备用金/国债
3. **期末**：期末业务 → 月末结转（可重复）；年底 → 年度结转；改账后重新点结转即可
4. **报表**：账簿查询 → 财务报表（三张表 + PDF/打印/Excel）；四级账簿 → 分户余额表/对账单
5. **财务账套启用**：试算与对账 → 按小区生成期初凭证 → 历史补账 → 日常自动汇总记账

## 六、数据备份

所有数据 = 数据库文件 + 附件目录：

- `server/vfund.db`（WAL 模式下含 `vfund.db-wal/-shm`，备份时一同复制或先停服务）
- `server/uploads/`（凭证附件）
- `server/reports/`（月报与财务报表快照，可重新生成）

恢复 = 文件放回原位重启后端。
