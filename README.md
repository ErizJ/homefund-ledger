# 住房维修基金记账系统（homefund-ledger）

面向住建局代管住房维修基金场景的单机记账系统，前后端分离架构：

- **后端**：Go + Gin + SQLite（modernc 纯 Go 驱动，免 CGO），端口 `8080`
- **前端**：Vue3 + Vite + Element Plus，端口 `5173`（开发模式自动代理 `/api` 到后端）
- **数据**：本地 SQLite 文件 + 附件目录，全部数据不出本机

## 功能总览

### 四级账体系

```
一级 总账（全局汇总）
 └─ 二级 小区账（每个小区一本账）
     └─ 三级 楼洞账（每个楼洞一本账）
         └─ 四级 住户账（每户一账，所有收支流水落到最细级）
```

上级余额自动逐级汇总；小区余额 = 户账合计 + 公共账（利息等未分摊项）。

### 核心功能

| 模块 | 菜单位置 | 说明 |
|---|---|---|
| 首页 | 首页 | **三大日常录入快捷入口（录入收款/维修支出/利息，点击直达表单）**、总余额、今日/本月收支、最近录入列表（最近 8 笔）、月/年/日汇总表（打印/导出 Excel） |
| 日常录入 | 日常录入 | 面向普通工作人员的简化录入表单：**录入收款**（小区→楼洞→户号联动、自动显示户主/面积/当前余额、缴款方式、附件）、**录入维修支出**（分摊范围选择、保存前二次确认金额与户数、自动按建筑面积分摊尾差归末户）、**录入利息**（挂小区公共账）；表单大字体大按钮，保存后自动生成业务凭证并联动财务账套 |
| 住户管理 | 住户管理 | 住户台账：关键字搜索（户主/户号/小区/楼洞）、当前余额（与四级账同源实时计算）、手工新增住户、编辑户主/面积、点击住户查看**收支流水与逐笔余额** |
| 凭证记账 | 账务查询 → 凭证记录 | 完整凭证管理：四类凭证记账、连续编号、附件（≤20MB）、打印（含分摊明细与签字栏）、分摊通知单、作废（留痕，级联作废分摊子凭证与财务凭证）、导出 Excel |
| 四级账簿 | 账务查询 → 四级账簿 | 总账→小区→楼洞→住户逐级点击钻取；选中小区可打印/导出**分户余额表**，可打印/导出**小区对账单**（选年度，含期初/期末余额、分月发生额，供与业委会/物业核对） |
| 基础数据 | 更多 → 基础数据导入 | Excel/CSV 导入住户（含期初余额）、下载导入模板、手工建小区/楼洞 |
| 月结锁账 | 月结锁账 | 月结后当月凭证禁止新增/作废/传附件；支持反结转解锁；月结月份可打印月度汇总表 |
| 银行对账 | 银行对账 | 导入银行流水 Excel/CSV，系统按同金额找出候选凭证人工确认匹配；未匹配的标记未达账项或忽略 |
| 财务账套 | 财务账套 | 财会〔2020〕7号科目体系（38个科目预置，含公有住房/国债专户），收付实现制借贷记账；业务单据自动生成借贷分录（交存→借银行贷交存收入、利息→借银行贷利息收入、支出→借维修支出明细贷银行）；**手工填制记账凭证**（借贷平衡自动校验）；**总分类账**（三栏式：期初/本期借贷/期末，按一级科目汇总，可打印）；科目余额表/明细账（含项目辅助核算）；试算平衡；**月末结转**（收入支出并入净资产）：月结锁账时自动生成，也可在财务账套「总账」页手工执行期末转账（不锁账、可重复、只结转新增部分，月结时自动重算避免双重结转）；净资产↔业务台账双线对账；**历史补账**（一键为启用财务账套前的老凭证补记财务凭证） |

## 启动方式

### 1. 启动后端（二进制已编译好，直接运行）

```bash
cd /Users/zhengjia/projs/vfund-ledger/server
./vfund-server
```

- 数据库文件默认为当前目录下的 `vfund.db`，附件存放在当前目录的 `uploads/`
- 可自定义数据库路径：`./vfund-server /path/to/vfund.db`（换路径 = 换一套独立账）
- 启动成功会输出 `服务已启动: http://127.0.0.1:8080`

### 2. 启动前端

```bash
cd /Users/zhengjia/projs/vfund-ledger/web
npm run dev
```

然后浏览器打开 **http://127.0.0.1:5173**

> 如果前端依赖丢失，先执行 `npm install` 再 `npm run dev`。

### 3. （可选）重新编译后端

本机 Go 工具链装在隔离目录，编译时需要带上环境变量：

```bash
cd /Users/zhengjia/projs/vfund-ledger/server
export PATH=~/.workbuddy/binaries/go/go/bin:$PATH
export GOPATH=~/.workbuddy/binaries/go/gopath
export GOPROXY=https://goproxy.cn,direct
go build -o vfund-server .
```

## 使用流程

### 普通工作人员（日常操作）

1. **首页 → 点「＋ 录入收款」** → 选小区 → 选楼洞 → 选户号（自动显示户主/面积/余额）→ 输金额 → 保存
2. **维修支出**：首页 →「＋ 录入维修支出」→ 选分摊范围 → 填项目和金额 → 确认户数提示 → 保存（系统自动分摊到户）
3. **查住户**：住户管理 → 搜索户主/户号 → 点行看收支流水和余额

### 首次建账

1. **建小区/楼洞**：更多 → 基础数据导入 → 手工创建，或 Excel 导入时自动创建
2. **导入住户**：更多 → 基础数据导入 → 下载导入模板 → 填好 → 选择文件导入。列头必须是：
   `小区 | 楼洞 | 户号 | 户主 | 建筑面积 | 期初余额`
   （同一小区+楼洞+户号重复导入会更新而非重复插入；也可在「住户管理」逐户新增）
3. **月底**：月结锁账 → 选月份执行月结（月结后发现要改账，先反结转，改完再重新月结）
4. **对账**：银行对账 → 导入银行流水（列头：`日期 | 金额 | 摘要`，日期格式自动归一化）→ 逐笔点「找凭证」核对匹配
5. **财务账套**（可选启用）：财务账套 → 对账页签按小区「生成期初凭证」（金额取住户期初余额合计）→ 若有启用前的老凭证点「历史补账」→ 之后每张业务单据自动生成财务凭证，月末结转自动并入净资产；也可在「填制凭证」页签手工编制记账凭证
6. **打印与导出**：
   - 凭证列表：凭证「打印」（记账凭证）、「通知单」（分摊通知单，每户一张）、列表「导出 Excel」
   - 概览页：月度/年度/每日汇总「导出 Excel」，「打印月报」「打印年报」
   - 四级账簿（选中小区后）：「打印/导出分户余额表」「打印/导出对账单」（对账单可选年度）
   - 月结页：「打印月报」

## 数据备份

所有数据就是这两个东西，复制走即完成备份：

- `server/vfund.db`（全部账目数据）
- `server/uploads/`（凭证附件文件）

恢复 = 把文件放回原位重启后端。

## 目录结构

```
vfund-ledger/
├── server/            # Go 后端
│   ├── main.go        # 入口 + 建表
│   ├── handlers.go    # 基础数据/凭证/附件接口
│   ├── ledger.go      # 四级账、日/月/年汇总、小区对账单接口
│   ├── periods.go     # 月结/反结转
│   ├── bank.go        # 银行流水导入与对账
│   ├── attachments.go # 附件上传下载
│   ├── gl.go          # 财务账套（科目/凭证/结转/试算/对账/补账）
│   ├── vfund-server   # 编译好的二进制
│   ├── vfund.db       # SQLite 数据库（运行后生成）
│   └── uploads/       # 附件目录（运行后生成）
└── web/               # Vue3 前端
    ├── src/pages/     # Dashboard / DailyEntry / Households / Vouchers / Ledger / BasicData / Periods / Bank / GL
    ├── src/store.js   # 跨页导航状态（首页卡片 → 日常录入）
    ├── src/api.js     # axios 封装
    ├── src/print.js   # 打印工具
    └── src/export.js  # Excel 导出工具
```

## 注意事项

- 后端只监听 `127.0.0.1`，不对外网开放；多人同时使用需另做部署（改监听地址 + 反向代理）
- 本机 curl 测试 API 时如走系统代理会连不上本地端口，加 `--noproxy '*'`
- 作废凭证只留痕不删除；月结月份的数据被锁定，误操作需反结转后处理
- 建议始终用绝对路径指定数据库启动（如 `./vfund-server /Users/zhengjia/projs/vfund-ledger/server/vfund.db`），附件目录自动建在数据库同级的 `uploads/`，不受启动时所在目录影响
- 数据库使用 WAL 日志模式（`vfund.db-wal`/`vfund.db-shm` 是正常文件，勿单独删除；备份时连同主文件一起复制，或先停服务）
- 余额口径：户余额 = 期初建账 + 缴纳 − 分摊；小区余额 = 户账合计 + 公共账（利息）；对账单期末余额与四级账簿实时汇总一致
- 财务账套差额①在月末结转前会等于「未结转的收支净额」，属正常现象；逐月结转后差额应为 0
- 业务凭证作废时自动级联作废对应财务凭证；业务/结转/期初类财务凭证不能在财务账套里直接作废（须回业务端操作或反结转）
